# Starter datasets

Two independent sets of three public documents each, curated by Superjoin for the assignment (≤100 pages each):

- `delhivery/` — Delhivery Limited: 2022 prospectus excerpt, FY2023-24 annual report excerpt, Q4 FY24 earnings presentation.
- `india-macroeconomy/` — Economic Survey 2024-25, RBI Annual Report 2024-25, IMF India 2025 Article IV (excerpts).

Each subfolder's README lists the original source URL and which original pages were retained. Printed page
numbers inside the excerpts follow the originals and therefore jump; this project keys evidence on the PDF page index.
